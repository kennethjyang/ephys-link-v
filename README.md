# Ephys Link V

Electrophysiology manipulator communication platform.

## Installation for use
Download the executable for your platform from the [releases page](https://github.com/kennethjyang/ephys-link-v/releases/latest) and run it. 

## Installation for development

1. Install UV.
2. Run `uv sync` to install the environment.
3. Run `uv run lefthook` install to set up hooks.

## Platform Support

Sensapex is currently disabled on macOS due to the lack of a natively shipped macOS binary.
